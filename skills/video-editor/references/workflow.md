# Definition workflow

Start from the repository's [runnable examples](../../../docs/VIDEO_DEFINITIONS.md).
Put footage, an overlay image and a separate music track in one definition. Use
`sourceIn` and `sourceOut` to select the source range, and `at` to position it
on the timeline. Use a separate track for an overlay and set its visual
properties on the clip. Keep captions in the definition's `subtitles` object.

Validate the draft, watch it or preview individual frames, then render the
final MP4. Use version control to record decisions.
